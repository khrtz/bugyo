# 常駐エージェント（設計）

状態: 設計のみ・未実装。このページのコマンド（`bugyo agent`、`bugyo inbox`、`bugyo reply`、`bugyo run`）はまだありません。

名前と担当を持つエージェントが常駐し、見回り、タスクを作り、作業用のセッションに任せ、結果を人に持ってくる層です。[タスク台帳と門番](tasks.md) の上に載せます。

常駐エージェントは製品コードを書きません。コードを書くのは作業セッションで、完了かどうかを決めるのは台帳の判定です。

## 巡回

常駐エージェントは `.bugyo/agents/<名前>.md` の1ファイルで定義し、決まった間隔で「巡回」を1回ずつ実行します。巡回1回は `claude -p` の起動1回で、動き続けるプロセスは持ちません。記憶をすべてファイルに残すので、途中で落ちても次の巡回で続きから再開できます。

1回の巡回でやることは次の6つです。

1. **読む。** 自分の記憶（`.bugyo/agents/<名前>/memory.md`）、人からの返事、タスク台帳、CI の結果、担当機能の feature map を読む。ここは常に読み取り専用
2. **決める。** やることを1つ選ぶ。タスクを作る、着手できるタスクを任せる、終わった作業の証拠を確かめる、人に聞く、のどれか
3. **ルールに照らす。** その行動のルールが「聞いてからやる」なら、実行せずに質問を残して終わる
4. **任せる。** コードを書く仕事は作業セッションに渡す
5. **持ってくる。** `done` が通ったら、証拠つきの PR と3行の要約を人に届ける。通らなければ、理由を付けてもう一度任せるか、人に渡す
6. **覚える。** 分かったことと次にやることを `memory.md` に書いて終わる

## ルール

行動ごとに、次の4種類から1つを選びます。

| ルール | 意味 |
| --- | --- |
| 自分でやる | 聞かずに実行する |
| 頼まれていればやる | 人がその行動をはっきり頼んだときだけ実行する |
| 聞いてからやる | 質問を残して止まり、返事を待つ |
| 人に渡す | 自分ではやらず、人の仕事として渡す |

設定で変えられない決まりがあります。次の行動は、ルールをどう書いても常に「人に渡す」です。

- lint ルールやテストの無効化・削除
- `CLAUDE.md`、エージェント定義、ルール自体の変更
- 証拠ファイルの編集
- `main` へのマージ（門番が合格するまで）

「作業セッションに任せる」と「PR を開く」も、門番が合格するまでは「聞いてからやる」より緩くできません。

## 人とのやり取り

質問と報告は `.bugyo/inbox/` に1件1ファイルで残します。質問には選択肢を付けます。形をファイルで固定しておくので、あとでチャットや PR のコメントに繋ぎ替えられます。

| コマンド | すること |
| --- | --- |
| `bugyo agent new <名前> --role <役>` | 定義ファイルを雛形から作る |
| `bugyo agent tick <名前>` | 巡回を1回実行する。スケジューラから呼ぶ |
| `bugyo agent ls` / `pause <名前>` | 一覧と状態、一時停止 |
| `bugyo inbox` | エージェントからの質問と報告の一覧 |
| `bugyo reply <id> "<返事>"` | 質問に答える。次の巡回でエージェントが読む |

## 役

最初に用意する役は4つで、動かすのは番人1体からです。

| 役 | 担当 | 最初のルール |
| --- | --- | --- |
| 番人 | `verify --all` を定期的に回し、落ちた機能に再現テストつきのバグ修正タスクを作る | タスク作成は自分でやる。修正を任せるのは聞いてから |
| 実装係 | 着手できるタスクを作業セッションに任せ、`done` まで見届ける | 任せるのも PR を開くのも聞いてから |
| 査読係 | 開いた PR を証拠から先に見て、指摘をコメントする | コメントは自分でやる。承認は人に渡す |
| 規則係 | ミスの記録を見て、2回目になった種類のルール案を作る | 案を作るのは自分でやる。ルールの追加は人に渡す |

## 作業セッション

作業セッションは、1タスク＝1 worktree＝1ブランチ＝1回の `claude -p` です。常駐エージェントはこれを呼んで仕事を任せます。

- **`bugyo run <id>`**: worktree を作る → `start` → エージェントを起動して `show` の出力を渡す → 終わったら `done` → PR を開く
- **`bugyo run --ready -n 3`**: 着手できるタスクから、`feature` が重ならないものだけを選ぶ。同じ機能を2体が同時に触らない
- **二重着手の防止**: worktree 同士はお互いの `.bugyo/tasks` が見えないので、着手の印は、すべての worktree から見える git の共通ディレクトリに置く
- **許可するコマンド**: `pnpm` と `bugyo` に絞る
- **マージ**: 最初は人が PR の証拠を見てマージする。自動マージはいちばん最後で、条件は「門番が合格」「CI が通っている」「そのタスクの `evidence-tree` が今のコードと一致」の3つ

複数を同時に走らせるのは最後です。
