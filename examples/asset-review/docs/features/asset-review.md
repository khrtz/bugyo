# アセットレビュー

## 何があるか
- 3Dアセットの一覧、状態別の絞り込み、選択したアセットの検査結果とレビュー欄。
- ファイル名、三角形数、テクスチャ容量を検査し、承認またはコメント付き差し戻しを記録する。
- 新しいアセットを登録できる。追加アセットとレビュー結果は、このブラウザの localStorage に残る。

## どう辿り着くか
- ルート `/` を開く。左の状態別メニューで絞り込み、一覧の行を選ぶと右に詳細が出る。

## どう操作して確かめるか
- `pnpm verify asset-review`
- 成功：最初の4件から正常なアセットを選び「承認する」。承認済みの件数と絞り込みが更新される。
- 入力：新規登録フォームから規則に合わない名前、80,001 tris、257 MBを入力すると、詳細に3件の指摘が出て承認できない。
- 差し戻し：コメントが空なら保存できない。理由を記入して差し戻すと状態が変わる。
- 空：「承認済み」を選び、該当件数が0なら空の案内が出る。
- 永続化：承認・追加・差し戻しの後にページを再読み込みしても結果が残る。

## よく嘘をつくところ
- 一覧のバッジだけ変わって、集計・絞り込みや再読み込み後の状態が変わらないこと。
- 基準値ちょうどを誤って失格にし、超過したアセットを承認できてしまうこと。
- `verify` はDOM上で登録・承認・保存を操作し、実ブラウザのE2Eは `pnpm e2e` とCIで確かめる。
- これはローカルのレビュー台帳であり、ファイルそのものの3D構造は解析していない。
