# hours

## 何があるか
- 営業時間の一覧（曜日ごとの3行）を出す静的なページ

## どう辿り着くか
- `site/index.html` をブラウザで開く

## どう操作して確かめるか
- `pnpm verify hours`（`checks/hours.mjs` がページを読み、題名と3行を確かめる。出力は `artifacts/verify/hours.log` に残る）
- 成功：題名が Opening hours で、平日・土曜・日曜の3行がこの順に並ぶ
- エラー：行が足りない・順番が違うと、どの行が違うかを出して終了コード 1
- 空：一覧が空なら、行が足りないとして落ちる

## よく嘘をつくところ
- 見た目は同じでも、`<li>` を `<p>` に変えると一覧として読まれなくなる
- ダッシュは全角の「–」。半角の「-」に変わっていたら壊れている
